# RNG Pedras

Jogo web em HTML/CSS/JavaScript: rolagem RNG de apelidos + jogo de tiro em pedras.

## Como jogar
- Clique em **ROLAR RNG** para sortear o apelido/raridade.
- Cada raridade muda dano e vida do jogador.
- Clique/tape nas pedras para atirar.
- Cada pedra derrotada vale **100 pontos**.
- Mítico e Secreto ativam efeitos especiais na tela.

## Publicar no GitHub Pages
1. Crie um repositório no GitHub.
2. Envie `index.html`.
3. Vá em **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/root`.
6. Salve e abra o endereço do GitHub Pages.

> Observação: as chances informadas somam 96,5%. Para o jogo não ficar sem resultado, os 3,5% restantes são tratados como COMUM.
